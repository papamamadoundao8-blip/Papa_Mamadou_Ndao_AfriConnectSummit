# Description
AfriConnect Summit est un site web vitrine moderne conçu pour une conférence tech panafricaine réunissant développeurs, entrepreneurs et investisseurs. Ce dernier est réalisé intégralement avec les technologies web fondamentales à savoir (HTML5, CSS et JavaScript), le projet propose une expérience utilisateur fluide répartie sur 4 pages clés (Accueil, Programme, Intervenants et Contact). Il intègre des fonctionnalités dynamiques avancées telles qu'un mode sombre persistant, le filtrage interactif des intervenants, la gestion d'onglets pour le planning, des animations fluides au scroll ainsi qu'un formulaire avec validation en temps réel.

# Technologies utilisées
- HTML : Pour la structure sémantique des pages
- CSS : Pour la stylisation, le Bento grid, les animations et la responsivité
- Font Awesome : Pour les icônes
- Google Fonts : Pour les polices
- JavaScript : Pour le thème clair, le compteur animé, le filtrage des intervenants et la validation du formulaire
- GitHub : Pour enregistrer chaque étape de notre projet

# Les fonctionnalités JavaScript utilisées dans ce projet
- Dark mode et Light mode : intégré dans la navbar et sauvegardé dans localStorage
- Compteurs animés : s'incrémentent de 0 à leur valeur finale
- Filtrage des cartes Intervenant par catégorie sans rechargement de la page
- Validation du formulaire : champs requis, regex sur l'email, longueur minimum 20 caractères pour le message, messages d'erreur et de succès personnalisés
- Navbar dynamique qui change de style au scroll
- Animations fade-in : les sections apparaissent en fondu à l'entrée dans le viewport
- Système d'onglets pour le programme : gestion de l'affichage des plannings sur 3 jours via des écouteurs d'événements au clic
- Année dynamique dans le footer : intégration automatique de l'année en cours dans le bas de page
- Compte à rebours en temps réel : calcul et mise à jour dynamique des jours, heures, minutes et secondes restants jusqu'à la date de l'événement
